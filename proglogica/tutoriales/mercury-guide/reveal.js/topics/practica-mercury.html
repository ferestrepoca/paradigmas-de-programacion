Parte práctica · Ejercicio 1

Hecho y regla

Problema

Completa una regla que indique si una persona tiene la edad mínima para participar.

  • El predicado recibe una edad entera.
  • Debe tener resultado semidet.
  • La condición mínima es 18.
Primer ejercicio. Que el público complete dos huecos. Respuesta: el modo es semidet, y la condición es Edad >= 18. Pregunta para ellos: ¿por qué semidet y no det? Porque con 15 la regla falla.
Parte práctica · Ejercicio 2

Suma recursiva

Problema

Completa la relación que suma todos los enteros de una lista.

  • La lista vacía suma 0.
  • En una lista no vacía, suma la cabeza y el resto.
  • El resultado debe salir por el argumento out.
Segundo ejercicio, recursión sobre listas. Caso base: la lista vacía suma 0. Caso recursivo: Total = Cabeza + SumaResto. Destacar que el compilador acepta det porque cubre los dos casos de la lista: vacía y no vacía.
Parte práctica · Ejercicio 3

Factorial con modos

Problema

Completa el caso base y la llamada recursiva de factorial.

  • Si N =< 0, el resultado es 1.
  • Si no, resta uno y calcula el factorial del resto.
  • Finalmente multiplica ambos resultados.
Tercer ejercicio. Respuestas: el caso base es 1, la llamada es factorial(N1, Subresultado) y el resultado es Resultado = N * Subresultado. Punto clave: usamos if-then-else para que el compilador acepte det, porque cubre todos los enteros, incluso los negativos. Con dos cláusulas sueltas, factorial(0, 1) y otra con N > 0, Mercury no podría garantizar una solución para N negativo.
