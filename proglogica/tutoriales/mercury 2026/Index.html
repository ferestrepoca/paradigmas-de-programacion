Módulos

Encapsulación con interfaz pública

Encapsulación 
:- module matematicas.
:- interface.
:- import_module int.
:- pred suma(int::in, int::in, int::out) is det.
:- pred producto(int::in, int::in, int::out) is det.

:- implementation.
suma(X, Y, Z)     :- Z = X + Y.
producto(X, Y, Z) :- Z = X * Y.
⚖️

Predicados vs Funciones

Dos formas complementarias de expresar cómputo

% Predicado: relación (puede fallar, multi-solución)
:- pred duplicar(int::in, int::out) is det.
duplicar(X, Y) :- Y = X * 2.

% Función: retorna valor (usable en expresiones)
:- func cuadrado(int) = int.
cuadrado(X) = X * X.

% Uso en expresiones:
%   duplicar(5, Y)  → Y = 10
%   cuadrado(5)     → 25  (en una expresión)
🔄

Sistema de Modos

Declaran la dirección del flujo de datos para cada argumento

::in Entrada (instanciado al llamar) ::out Salida (libre, se unifica) ::di Destructive Input (I/O) ::uo Unique Output (I/O) 
% 2 entradas, 1 salida → siempre det
:- pred sumar(int::in, int::in, int::out) is det.
sumar(A, B, C) :- C = A + B.

% Entrada puede ser "ground" o libre
:- pred clasificar(int::in, string::out) is det.

% I/O siempre usa di / uo
:- pred main(io::di, io::uo) is det.
main(!IO) :-
    io.write_string("Hola\n", !IO).
🎯

Declaraciones de Determinismo

Mercury obliga a declarar cuántas soluciones puede tener un predicado

det Exactamente 1 solución, nunca falla
semidet 0 ó 1 soluciones (puede fallar)
nondet 0 ó más soluciones (backtracking)
multi 1 ó más soluciones (≥1 garantizada)

💧 I/O Puro con !IO

El estado de I/O se pasa explícitamente — el compilador verifica el orden

Sin azúcar sintáctica

main(IO0, IO) :-
  io.write_string(
    "Hola\n", IO0, IO1),
  io.write_string(
    "Mundo\n", IO1, IO).

Con !IO (equivalente)

main(!IO) :-
  io.write_string(
    "Hola\n", !IO),
  io.write_string(
    "Mundo\n", !IO).

¿Por qué es importante?

  • El compilador verifica el orden correcto de operaciones
  • No hay efectos secundarios implícitos → código puro
  • I/O determinista y predecible

⚖️ Mercury vs Prolog — Diferencias Clave

Comparativa directa entre los dos principales lenguajes de programación lógica

Característica Prolog (1972) Mercury (1995)
Sistema de Tipos Dinámico Estático con inferencia
Modos de argumentos Implícitos (ocultos al programador) Declarados explícitamente
Determinismo Implícito, en tiempo de ejecución Declarado y verificado por compilador
Entrada/Salida Predicados impuros Estado explícito (completamente puro)
Corte (!) Soportado (ensucia la semántica) No existe → if-then-else
Rendimiento Interpretado Compilado a C nativo
assert / retract Soportado (estado mutable global) No existe → datos inmutables
Sistema de módulos Limitado o ausente Sistema completo con interfaz

Ejemplos de Código

De lo básico hasta la programación lógica pura con backtracking

Factorial
factorial.m · Funciones con pattern matching
det 
:- module factorial.
:- interface.
:- import_module io.
:- pred main(io::di, io::uo) is det.
:- implementation.
:- import_module int.

:- func factorial(int) = int.
factorial(0) = 1.
factorial(N) = N * factorial(N - 1)
    :- N > 0.

main(!IO) :-
    io.format("5!  = %d\n",
        [i(factorial(5))], !IO),
    io.format("10! = %d\n",
        [i(factorial(10))], !IO).
factorial(5) = 120
factorial(10) = 3628800
Fibonacci
fibonacci.m · Recursión + I/O
det 
:- func fib(int) = int.
fib(0) = 0.
fib(1) = 1.
fib(N) = fib(N-1) + fib(N-2)
    :- N > 1.

:- pred print_fibs(int::in,
    int::in, io::di, io::uo) is det.
print_fibs(I, Max, !IO) :-
    ( I < Max ->
        io.format("fib(%d) = %d\n",
            [i(I), i(fib(I))], !IO),
        print_fibs(I + 1, Max, !IO)
    ;
        true
    ).
fib(0) = 0
fib(1) = 1
fib(2) = 1
fib(3) = 2
fib(4) = 3 ...

Manipulación de Listas
listas.m · Suma, máximo, filtrado
det semidet 
:- import_module list, int.

% Suma recursiva
:- func suma_lista(list(int)) = int.
suma_lista([]) = 0.
suma_lista([H|T]) = H + suma_lista(T).

% Máximo (semidet: falla si lista vacía)
:- pred maximo(list(int)::in, int::out)
    is semidet.
maximo([X], X).
maximo([H|T], Max) :-
    maximo(T, MaxT),
    ( H > MaxT -> Max = H ; Max = MaxT ).

% Filtrar números pares
:- pred filtrar_pares(list(int)::in,
    list(int)::out) is det.
filtrar_pares([], []).
filtrar_pares([H|T], R) :-
    filtrar_pares(T, RF),
    ( H mod 2 = 0 -> R = [H|RF]
    ;                R = RF ).
Tipos Algebraicos
formas.m · Área y perímetro con pattern matching
ADT 
:- import_module float, math.

:- type forma
    --->    circulo(float)
    ;       rectangulo(float, float)
    ;       triangulo(float, float, float).

:- func area(forma) = float.
area(circulo(R))      = math.pi * R * R.
area(rectangulo(A,B)) = A * B.
area(triangulo(A,B,C)) = Ar :-
    S = (A + B + C) / 2.0,         % Herón
    Ar = math.sqrt(S*(S-A)*(S-B)*(S-C)).

:- func perimetro(forma) = float.
perimetro(circulo(R))      = 2.0*math.pi*R.
perimetro(rectangulo(A,B)) = 2.0*(A+B).
perimetro(triangulo(A,B,C))= A+B+C.
Búsqueda con Backtracking
busqueda.m · Predicado nondet + recolección con solutions/2
nondet 
:- import_module list, int, solutions.

% Pertenencia (nondet: múltiples soluciones)
:- pred pertenece(T::out, list(T)::in)
    is nondet.
pertenece(X, [X|_]).
pertenece(X, [_|T]) :- pertenece(X, T).

% Pares que suman N (nondet)
:- pred par_suma(int::in, list(int)::in,
    int::out, int::out) is nondet.
par_suma(N, Lista, X, Y) :-
    pertenece(X, Lista),
    pertenece(Y, Lista),
    X < Y,
    X + Y = N.

:- type par ---> par(int, int).
% solutions/2 recolecta TODOS los resultados
% del predicado nondet en una lista
main(!IO) :-
    Lista = [1,2,3,4,5,6,7,8],
    Obj = 9,
    solutions(
        (pred(par(X,Y)::out) is nondet :-
            par_suma(Obj,Lista,X,Y)),
        Soluciones),
    io.format("Pares que suman %d:\n",
        [i(Obj)], !IO),
    list.foldl(
        (pred(par(X,Y)::in,
              !.IO::di, !:IO::uo) is det :-
            io.format("  %d + %d\n",
                [i(X),i(Y)], !IO)),
        Soluciones, !IO).
Módulo: Pila Abstracta
pila.m · Tipo abstracto + interfaz completa
Tipo Abstracto 
:- module pila.
:- interface.
:- import_module list.

% Tipo abstracto (implementación oculta)
:- type pila(T).

:- func pila_vacia = pila(T).
:- pred push(T::in, pila(T)::in,
    pila(T)::out) is det.
:- pred pop(pila(T)::in, T::out,
    pila(T)::out) is semidet.   % falla si vacía
:- pred peek(pila(T)::in, T::out) is semidet.
:- func tamanio(pila(T)) = int.

:- implementation.
% Internamente: lista (detalle oculto)
:- type pila(T) ---> pila(list(T)).

pila_vacia = pila([]).
push(E, pila(L), pila([E|L])).
pop(pila([H|T]), H, pila(T)).
peek(pila([H|_]), H).
tamanio(pila(L)) = list.length(L).
Solucionador N-Reinas
n_reinas.m · Backtracking puro · 92 soluciones para N=8
nondet 
:- import_module int, list, solutions.

% Verificar posición segura
:- pred segura(int::in, int::in,
    list(int)::in) is semidet.
segura(_, _, []).
segura(Fila, Col, [RC|Resto]) :-
    RF = list.length(Resto) + 1,
    Col \= RC,                  % misma columna
    abs(Col-RC) \= abs(Fila-RF),% diagonal
    segura(Fila, Col, Resto).

% Colocar N reinas recursivamente
:- pred reinas(int::in, int::in,
    list(int)::in, list(int)::out) is nondet.
reinas(N, F, Acc, Sol) :-
    ( F > N -> Sol = Acc
    ; between(1, N, Col),
      segura(F, Col, Acc),
      reinas(N, F+1, [Col|Acc], Sol) ).

main(!IO) :-
    solutions(reinas(8,1,[],), Sols),
    io.format("Total soluciones: %d\n",
        [i(list.length(Sols))], !IO).

I/O Compleja con Manejo de Errores
calculadora_io.m · Lectura interactiva · tipos de operación · guardas
semidet det 
:- import_module int, string, char, list.

% Tipo algebraico para operaciones
:- type operacion
    --->    suma
    ;       resta
    ;       multiplicacion
    ;       division.

:- pred parse_operacion(string::in,
    operacion::out) is semidet.
parse_operacion("+", suma).
parse_operacion("-", resta).
parse_operacion("*", multiplicacion).
parse_operacion("/", division).

:- pred ejecutar(int::in, operacion::in,
    int::in, int::out) is semidet.
ejecutar(A, suma,         B, A + B).
ejecutar(A, resta,        B, A - B).
ejecutar(A, multiplicacion,B, A * B).
ejecutar(A, division,     B, A div B)
    :- B \= 0.    % guarda: no div/0
:- pred leer_entero(string::in,
    int::out, io::di, io::uo) is det.
leer_entero(Prompt, N, !IO) :-
    io.write_string(Prompt, !IO),
    io.read_line_as_string(Res, !IO),
    ( Res = ok(L),
      string.to_int(string.strip(L), N0)
    ->
        N = N0
    ;
        io.write_string("Inválido→0\n",!IO),
        N = 0 ).

main(!IO) :-
    io.write_string("=== Calculadora ===\n",!IO),
    leer_entero("Número A: ", A, !IO),
    leer_entero("Número B: ", B, !IO),
    io.write_string("Op (+,-,*,/): ", !IO),
    io.read_line_as_string(Op, !IO),
    ( Op = ok(S),
      parse_operacion(string.strip(S), Oper),
      ejecutar(A, Oper, B, Res)
    ->
        io.format("= %d\n", [i(Res)], !IO)
    ;   io.write_string(
            "Error o división por cero\n",!IO)
    ).

Cierre y Ecosistema

✓ Ventajas

  • + Errores de tipo detectados en compilación
  • + Rendimiento comparable a C
  • + Código puro y predecible
  • + Determinismo verificado en compilación
  • + Módulos con encapsulación real
  • + Sin corte (!) → semántica limpia

! Limitaciones

  • – Curva de aprendizaje pronunciada
  • – Comunidad pequeña, pocas librerías
  • – Más verbosidad que Prolog
  • – Sin assert/retract → sin estado mutable
  • – Soporte de IDEs limitado
  • – Documentación principalmente en papers académicos

◈ Aplicaciones Reales

  • ▸ Compiladores y análisis estático
  • ▸ Sistemas de verificación formal
  • ▸ IA y sistemas expertos
  • ▸ Procesamiento de lenguaje natural
  • ▸ Software de alta integridad
  • ★ El compilador Mercury está escrito en Mercury
